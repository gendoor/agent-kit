---
description: Сохранить итог сессии в project-memory и Mempalace
---

Загрузи навык `agent-kit-memory`. Зафиксируй итог текущей сессии по
`project-memory/session-protocol.md`, раздел «Перед завершением работы».

1. Определи, сработал ли хотя бы один триггер значимости из
   `session-protocol.md`. Если нет, сообщи об этом и сохрани только краткий
   checkpoint в Mempalace.
2. Если триггер сработал: создай или обнови `CHG-*` (и ADR при
   необходимости), синхронизируй `baseline.yaml`, `change-log.md`,
   `component-map.md` и `open-questions.md`. Уровни baseline обновляй только
   по факту изменений.
3. Сохрани Mempalace checkpoint вызовом `mempalace_checkpoint` в крыло
   проекта (см. `AGENTS.md`, раздел «Mempalace»): краткий проверяемый итог с
   датой, результатом, ссылками на Git-файлы, выполненными тестами, блокерами
   и отмененными решениями. Раскладывай записи по комнатам из
   `project-memory/mempalace-rooms.md`.
4. Не сохраняй сырой диалог, полный diff, секреты и персональные данные.
5. Выведи перечень измененных файлов и созданных записей Mempalace.

Дополнительные указания пользователя: $ARGUMENTS
